# 品牌与 Logo

## 名称

**PalmRelay · 掌间接力**

- **Palm**：掌中的手机，也是用户始终拥有的控制权。
- **Relay**：用户交代目标，Agent 接棒执行，再把结果交回。
- **中文名**：掌间接力，表达手机上的协作过程。

建议标语：**把任务交给手机，把结果交还给你。**

产品描述：Android 手机上的执行型 Agent。

## Logo 概念

一个圆角手机轮廓，内部是一条连接两个端点的流动轨迹：

- 手机框代表真实设备与执行现场。
- 轨迹代表从目标到动作、再到结果的接力。
- 薄荷色端点代表任务发起，暖橙色端点代表结果交还。
- 顶部短线提示手机听筒；结构保持简洁，便于用作应用图标。

标识为本项目绘制的原创 SVG 几何图形，不依赖图标库、外部字体或远程资源。文字组合标使用系统字体回退，精确字形会随渲染环境变化。

## 使用规范

- 保留原始纵横比，不拉伸或压扁。
- 图标最小建议展示尺寸 32×32；更小场景应单独验证端点与线条可辨识度。
- 主图形四周留足空白，建议不小于图标边长的 1/8。
- 彩色图标已有底色；透明单色标根据背景选择高对比版本。
- 组合标使用深底，不在其上叠加第三方 App 的商标或用户截图。
- Android 圆形/圆角遮罩适配、动态主题与无障碍对比度在实现阶段验证。

## 写作语气

简短、准确、交代结果。

推荐：“已保存本次修改；还有一项需要你确认。”

避免：“全部搞定！”——实际只完成部分目标时，应说清完成范围和剩余事项。
